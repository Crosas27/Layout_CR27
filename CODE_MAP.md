## Follow the data

1. `wallModel.js` converts saved measurement strings to numeric inches. Blank **optional** fields get defaults; malformed fields stay invalid.
2. `layoutEngine.js` validates geometry and openings, then calls the sidewall or gable layout module.
3. Layout modules derive panel and rib positions from the same negative sheet offset.
4. `openingAnalysis.js` creates warning and cut records without moving panels.
5. Renderers display those records. Invalid geometry clears drawing and fabrication output.
6. Committed editor actions queue a transactional workspace save. Share links are separate from saving.

## Search terms inside the files

Search `ADD WALL`, `DELETE OPENING`, `OPENING BOUNDS`, `RIB CENTERS`, `SAVE ALL PROJECTS`, `INDEXEDDB`, `MEASUREMENT KEYPAD`, or `DRAWING OBJECT TARGETS`.

## Make a change safely

Work on a branch. Run `npm test` and `npm run check`. After changing any runtime file, regenerate the offline shell with `node scripts/update-cache.mjs`, then run checks again. Keep `main` as the field-safe version.
